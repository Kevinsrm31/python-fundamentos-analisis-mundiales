# Python — Fundamentos y Análisis de Datos: Mundiales de Fútbol

Curso de Python desde cero (variables, estructuras de datos, control de flujo, funciones) hasta análisis de datos con NumPy y Pandas, con un proyecto final de análisis exploratorio sobre los Mundiales de fútbol hasta 2014.

## Contenido

- [`notebooks/notebook-Python.ipynb`](./notebooks/notebook-Python.ipynb) — fundamentos de Python: tipos de datos, estructuras de datos (listas, tuplas, sets, diccionarios), control de flujo, bucles, funciones, NumPy y Pandas.
- [`notebooks/Proyecto world cups.ipynb`](<./notebooks/Proyecto world cups.ipynb>) — proyecto final: análisis exploratorio de los Mundiales de fútbol.
- [`data/`](./data) — datasets usados en los notebooks (`world_cups`, `pokedex`).

## Proyecto final: Mundiales de fútbol hasta 2014

- Limpieza de tipos y creación de columnas calculadas.
- Filtrado de campeones que ganaron jugando de locales.
- Cálculo de goles totales por partido y ranking de partidos con más goles.
- Promedio de goles por partido por edición del Mundial.
- Ranking histórico de goleadores a partir de texto libre (conteo de eventos de gol por jugador).
- Visualización de goles por Mundial con gráficos de barras.

## Tecnologías

Python · NumPy · Pandas · Matplotlib / Seaborn · Jupyter / Google Colab
